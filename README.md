# 🍯 Golden Dates

A modern and elegant landing page for a fictional premium dates brand, designed and developed from scratch with **HTML5 and CSS3**.

The project combines **web development, visual design, and user experience** to create a clean and premium digital presence for a fictional dates brand.

![Desktop Preview](img/fullpage-preview.png)

**🔗 Live Demo:** https://aminatre.github.io/golden-dates/
**🎨 Figma:** [Design file](https://www.figma.com/design/4lKCmWfRKfREl4G1PCmQPW/Gloden-Dates?node-id=91-65&t=5K84jtNQ9u7gKbVP-1)

> 🚧 **Status:** In progress – hero section and navigation are complete, further sections and the shop page are being built.

## ✨ Features

**Done**
- Fixed navigation bar
- Hero section with blurred glassmorphism effect
- Custom typography and visual styling
- Footer with navigation and branding

**In progress**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/aminatre/golden-dates.git
```

Navigate into the project folder:

```bash
cd golden-dates
```

Open `index.html` in your browser or run the project with a local development server such as **Live Server** in VS Code.

No additional setup required.
